# City Front - 桌面网页版 FPS

这是一个使用 Cocos Creator 3.8.7 和 TypeScript 制作的桌面 Web 3D FPS。当前版本包含单机 12 对 12、联机房间、AI 补位、16 张战术地图和多层建筑掩体。

## 开始游戏

1. 使用 Cocos Creator 3.8.7 打开本目录。
2. 构建平台选择 **Web Desktop**，输出目录保持为 `build/web-desktop`。
3. 双击 `start-web.command`。
4. 浏览器打开 `http://127.0.0.1:7460`。

不要直接双击构建目录里的 `index.html`，资源和联机房间需要通过本地服务加载。

## 游戏模式

- 单机模式：选择阵营和已解锁主武器后直接开始，战场与任务自动随机，双方各 12 人，其他位置由 AI 控制。
- 联机模式：创建房间会生成 6 位房间码；其他玩家输入房间码加入。房间最多 24 名真人，双方不足 12 人时由 AI 补齐。
- 房主负责开始和重新开始比赛。房主退出后，房间会自动迁移给下一名玩家。
- 房主迁移会同时交接最后一个权威世界快照，避免 AI、比分和据点重复初始化。
- 单局最长 10 分钟；开场先显示 5 秒任务简报，不再使用数字倒计时。
- 蓝方任务：争取据点、斩首行动、空降突入、情报回收等战术任务。
- 红方任务：争取据点、包围推进、破袭行动、伏击行动、司令部防卫。
- 任务会配发工兵铲、降落伞、爆破包、侦察终端或重型护甲等对应装备，并使用不同的完成条件。

## PC 操作

- `WASD`：移动
- 鼠标移动：观察
- 鼠标左键：射击
- 鼠标右键：单击切换开镜/退出开镜
- `Esc`：退出鼠标锁定并暂停
- `Tab`：临时释放鼠标，可点击手雷和医疗按钮
- `R`：换弹
- `1`：主武器
- `2`：Glock 17
- `Space`：跳跃
- `Z`：蹲下
- `X`：趴下
- `G`：投掷手雷
- `H`：使用医疗包

HUD 右下角同时保留“手雷”和“医疗”两个可点击按钮。网页版没有虚拟摇杆、触屏射击键或触屏开镜键。

## 内容

- 蓝队：M16、MP5、M249。
- 红队：AKM、AKS-74U、RPK、PKM。
- 双方副武器：Glock 17，17 发弹匣，半自动。
- M16、AKM、MP5、AKS-74U：30 发弹匣，600 发备用弹药。
- M249、PKM：150 发弹匣，1200 发备用弹药。
- RPK：75 发弹匣，750 发备用弹药。
- 地图：约 180 米 × 180 米的城市街区和军事基地随机出现，包含车辆、武器箱、沙袋、可进入建筑、地下站台、窗户、屋顶和梯子。
- 配件：红点、二倍、四倍、六倍瞄具，握把、伸缩/折叠枪托，以及强化、重型和加长精密枪管；购买与装备记录保存在浏览器本地。
- 等级与经验在两方共用，升级需求逐级增加，并按等级解锁双方对应武器及发放金币奖励。

## 联机部署

本地房间服务和网页共用 `7460` 端口。公网部署需要：

1. 安装 Node.js 20 或更新版本并执行 `npm install`。
2. 先生成 `build/web-desktop`，再执行 `npm start`。
3. 将站点部署到支持 WebSocket 的 HTTPS 服务；HTTPS 页面会自动使用 WSS。
4. 放行服务端端口，并配置域名、TLS 证书和反向代理的 WebSocket 升级头。

生产配置位于 `deploy/`，包含 systemd、Nginx、Caddy、日志轮转和版本化发布脚本；PM2 配置为 `ecosystem.config.cjs`。健康检查地址为 `/healthz`。正式服务只依赖 `ws`，不会回退到 Playwright 内部实现。

设置页面提供“重置存档”，会原子恢复 1000 初始金币、默认配件和设置，避免页面刷新期间的生命周期保存把旧余额写回。

当前联机采用房主权威的轻量首版架构，适用于私人房间试玩，不是完整商业反作弊服务器。
